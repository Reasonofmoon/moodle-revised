# Academy LMS 카탈로그 (A4 · 8페이지)

학원 맞춤형 올인원 LMS 도입 안내 카탈로그입니다.

- `Academy LMS Catalog.dc.html` : 카탈로그 원본 (doc-page / image-slot 컴포넌트, Industry 디자인 시스템 `_ds/`)
- `Academy LMS Catalog.pdf` : 인쇄·배포용 PDF (GIF는 대표 프레임으로 출력)
- `assets/` : 화면 캡처 12종, GIF 3종(레벨테스트 흐름 · 내 예약 조회 · 설정 생성기), 데모 신청 QR

화면 캡처는 실제 시스템을 `데모 영어학원` 정보로 바꿔 찍었습니다. 화면 속 학원명·연락처·인명·주소는 예시입니다.

## 미리보기

`file://`로 열면 스크립트가 막힐 수 있으니 이 폴더에서 정적 서버를 띄워 확인하세요.

```bash
cd docs/catalog
python -m http.server 8099
# http://localhost:8099/Academy%20LMS%20Catalog.dc.html
```
